# Editorial conventions
This document lists some of the agreed convetions for the documents the WebExtension Working Group produces.

## rfc2119 keywords
https://www.rfc-editor.org/rfc/rfc2119.txt specifies the keywords "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED",  "MAY", and "OPTIONAL".

In our texts these keywords should be written in lowercase. If these keywords are used they always carry the meaning as specified in rfc2119. To read the texts with uppercase equivalents, the following webExtension can be used: https://github.com/patrickkettner/rfc2119ify
