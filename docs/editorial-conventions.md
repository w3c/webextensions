# Editorial Conventions

This document lists some of the agreed conventions for the documents the WebExtensions Working Group produces.

## RFC 2119 Keywords

[RFC 2119](https://www.rfc-editor.org/rfc/rfc2119.html) specifies the keywords "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL".

In our texts these keywords should be written in lowercase. If these keywords are used they always carry the meaning as specified in RFC 2119. This intentionally departs from [RFC 8174](https://www.rfc-editor.org/rfc/rfc8174.html), which gives the keywords their special meaning only in uppercase. To read the texts with uppercase equivalents, the following web extension can be used: https://github.com/patrickkettner/rfc2119ify
